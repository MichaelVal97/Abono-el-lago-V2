# Abono-el-lago-V2

Ecommerce y sitio corporativo para venta de abono.

## Estructura

- `backend/`: API principal con NestJS y base preparada para microservicios
- `frontend/`: aplicación React
- `docs/`: arquitectura y decisión de dominios

## Base de escalabilidad

El backend queda organizado por dominios para que luego podamos separar servicios sin rehacer el proyecto.

## Siguiente paso

1. Scaffold real de NestJS en `backend/`.
2. Scaffold real de React en `frontend/`.
3. Configurar env, Cloudinary, Nodemailer y base de datos.
